Create a function called `filterStrings`. This function should take two parameters:

- `words` - an array of strings
- `maxLength` - the max length

The function should return an array of all the words that are shorter than or equal to the given max length. 

  

 **For example:**

```
var words = ["hello", "world", "foo", "bar"]
```

```
var results = filterStrings(words, 3);
```

```
console.log(results); //Will print ["foo", "bar"]
```
